# data/

Local working folder for datasets. **Everything in here except this README is git-ignored.**

- Never commit raw or identifiable student work (names, emails, student IDs, rosters, original submissions).
- De-identify data before it is used for labeling or model training.
- Test fixtures belong in `tests/fixtures/` or `ml/tests/fixtures/`, and must be synthetic or fully de-identified.

If you think a file needs to be shared, put it in the team Google Drive with the right access, not in this repo.
